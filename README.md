# Enrique Benito Casado — Portfolio

A static portfolio for my Data & AI architecture work, with a focus on Databricks, governed data platforms, and practical engineering evidence.

- `index.html` introduces the current focus and links to Databricks and my working knowledge base.
- `projects.html` presents selected engineering, architecture, and academic work with explicit validation status.
- `certifications.html` distinguishes available certificate files from historical learning records.
- `css/portfolio-refresh.css` contains the shared navigation, layout, and responsive styles.

## Preview locally

From the repository root, run:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000`. These pages use static HTML and CSS; content and navigation do not depend on JavaScript.

Before publishing a change, check the three pages at desktop and mobile widths, keyboard navigation, local file links (including filename case), and the accuracy of project and credential descriptions. The site is served through GitHub Pages.
